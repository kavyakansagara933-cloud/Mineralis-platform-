# MINERALIS — System Architecture & Engineering Specifications

This document outlines the technical architecture, data contracts, mathematical audit algorithms, and real-time telematics subsystem of **MINERALIS**.

---

MINERALIS employs a decoupled, asynchronous micro-architecture composed of three core tiers:

```

│                  APPLICATION API CORE (FastAPI)              │
```

## 2. Core Modules & Engine Specifications

### 2.1. Deterministic Calculation & Variance Engine
Unlike heuristic or probabilistic estimates, all operational variances are calculated deterministically using algebraic bounds:

$$\text{Variance (\%)} = \left( \frac{\text{Actual Production} - \text{Target Production}}{\text{Target Production}} \right) \times 100$$

$$\text{Composite OBR} = \frac{\sum \text{Overburden Excavated } (\text{M.CuM})}{\sum \text{Coal Extracted } (\text{MT})}$$

$$\text{Slope Factor of Safety (FoSL)} = \frac{\sum c' + (\sigma - u) \tan \phi'}{\sum \tau_{\text{shear}}}$$

### 2.2. Real-Time Telematics Subsystem
- **Endpoint**: `ws://127.0.0.1:8000/ws/telematics`
- **Cadence**: 2-second streaming interval with sub-millisecond serialization.
- **Payload Schema**:
  ```json
  {
    "timestamp": "2026-10-01T22:30:00Z",
    "unit_code": "EX-4201",
    "unit_type": "Electric Rope Shovel 42m3",
    "division": "Division B",
    "mine": "Central Seam Opencast Block",
    "status": "Operating",
    "telemetry": {
      "engine_rpm": 1492,
      "coolant_temp_c": 76.4,
      "hydraulic_pressure_bar": 284,
      "vibration_mm_sec": 1.72,
      "fuel_burn_lph": 118.5
    },
    "health_score": 96
  }
  ```

### 2.3. Statutory Audit Certification Subsystem
Every compliance certificate generated by the system creates an immutable SHA-256 ledger digest:
$$\text{Audit Seal} = \text{SHA-256}\left(\text{FiscalPeriod} \parallel \text{Division} \parallel \text{RulesPassed} \parallel \text{Timestamp}\right)$$
